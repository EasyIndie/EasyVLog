# 定位与调性

> 账号方向的**唯一来源**：定位、账号名、平台、调性、红线都在这。
> 实操（栏目 / 拍摄 / 发布）见 `02-选题与拍摄.md`。

---

## 1. 一句话定位

> 一个男生，在家学做饭。配方给你，翻车也给你看。

- **性质**：私人食谱收集 + 日常记录 + 食谱工具箱。
- **愿景**：认真做饭，认真生活。
- **目标**：把家常面食一样一样做明白，攒成自己的食谱库。
- **人设关键词**：新手 · 踏实 · 认真但不完美 · 只记录不抒情。

**观众为什么关注**：实用（能复刻 → 收藏）> 真实（会翻车 → 信任）> 踏实（陪伴感）。

**简介可用**：「一个男生，一口锅，慢慢学做饭。配方放屏幕，翻车也拍。」

## 2. 账号名

**毕业生食谱**——软双关，不是身份声明：

| 面向 | 读法 |
|---|---|
| 公开面 | 「学生的食谱」——人畜无害、审核友好 |
| 内部面 | 「毕业」是「被裁」的黑话——在家把食谱一样样攒起来 |

**红线**：留这个 wink 可以，内容**不能**往「失业生存指南」「被裁后怎么省钱」方向偏。

**改名是高风险操作**：先查商标（第 30 / 35 类），再全局替换文档 / `../data/backlog.json` / 分集标题与标签，并更新本文件与 `../CHANGELOG.md`。

## 4. 调性规范

**内核**：踏实、笃定、不慌。不是「我温柔地陪你」，而是「我自己也在笨拙但认真地生活，顺便给你个配方」。

**呈现方式**
- **不出镜**：只拍手、操作、案板、成品；不露脸、不露人。
- **无人声**：没有口播 / 旁白 / 配音，信息全部由**字幕**承载。
- **音频**：只有可选背景音（BGM 或现场环境声），也可完全静音；BGM 只用平台曲库。

**字幕**
- 去掉「呀 / 啦 / 哦 / 呢」等软虚词。
- 讲事实、步骤、失败原因，不讲情绪；每句一个信息点，短句。
- 每行别太长，手机上要一眼看完。
- 常用说法：「我试下来……」「说实话……」「这一步我踩过坑」。

**视角**：全程第一人称经验分享（我试了 / 我翻车了）。把「你应该」换成「我试下来」。

**教学口吻**

| ❌ 爹味 | ✅ 这样写 |
|---|---|
| 这样擀才中间厚边缘薄，很多人做错了 | 我试了好几次，中间厚一点不容易破 |
| 你必须二次醒发 | 我第二次醒发忘了，蒸出来就塌了 |
| 教你一个不出水的技巧 | 先油后盐，我上次没这样做，馅全是水 |

**画面**
- 干净：案板、灶台、背景清爽，避免「单身汉宿舍感」。
- 光线：暖白 / 自然光，不用粉色滤镜。
- 重点：手、揉面的力度、蒸汽、掰开的横截面。
- 生活物件：一杯水、一本摊开的书、窗外的树，把「宿舍」变「家」。

**红线（一票否决）**
1. 说教 / 居高临下
2. 卖惨、焦虑、自嘲
3. 过度抒情、演出来的温柔
4. 画面脏乱
5. 无合理解释的「不上班」暗示

## 5. 状态表达：不主动交代，也不否认

观众没有义务知道原因。

- **不主动交代、不解释、不卖惨。**
- **被问到就一句带过**：「最近在家，先把饭做好。」然后继续讲菜。只回一次，不展开。
- **绝对不用的词**：失业、被裁、毕业、下岗、找不到工作、gap、躺平、啃老（账号名「毕业生食谱」是唯一例外，完整护栏见 `../AGENTS.md` 第 2 节）。

## 6. 合规与风险

- **带货**：食品类目先看平台要求；优先平台供应链，避免自制食品直接售卖。
- **版权**：BGM 只用平台曲库。
- **肖像 / 声音**：朋友、室友出镜需口头或书面同意。
- **用火用电**：明火、蒸锅注意安全，平台会巡查。
- **翻车尺度**：可以翻车，但要给「原因 + 改进」，别长期只翻车。
