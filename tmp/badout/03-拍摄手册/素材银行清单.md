# 素材银行清单

> 平时随手拍，剪辑缺「呼吸感」镜头时随时调。
> 原则：**每次做饭/出门，顺手拍 2–3 条 5 秒空镜。**

## 厨房 / 案板
- [ ] 阳光落在案板上
- [ ] 面粉撒在台面的特写
- [ ] 手沾面粉
- [ ] 水龙头流水
- [ ] 灶火点燃
- [ ] 锅盖上的水汽

## 生活 / 家
- [ ] 窗外的树/天空/雨
- [ ] 摊开的书、笔记本
- [ ] 一杯水/一杯茶
- [ ] 绿植
- [ ] 猫/宠物（有就拍）
- [ ] 门外的走廊/电梯（出门时）

## 声音素材（单独录 5–10 秒）
- [ ] 切菜声
- [ ] 揉面声
- [ ] 油锅「滋啦」声
- [ ] 蒸汽/水沸声
- [ ] 敲鸡蛋、打蛋声
- [ ] 窗外的雨声/鸟叫

## 使用建议
- 每条视频开头/结尾各留 1 个空镜做呼吸感
- 转场用「蒸汽」「保鲜膜」「拿食材挡镜头」
- 素材多了以后，可以专门剪一条「没有台词的日常」生活向视频

## 存放
建议在硬盘/相册建 `素材银行/` 文件夹，按「厨房/生活/声音」分三类，文件名带年月，方便检索。
