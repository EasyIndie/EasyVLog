# 周末批量拍摄手册

> 适用：第 1–2 集（韭菜鸡蛋胡萝卜包 + 花卷），两条同为发面，共用面团。
> 分集脚本见 `../02-分集脚本/`。

---

## 0. 拍摄前决策（很重要）

1. **先跑通第一条。** 先按流程拍完「韭菜鸡蛋胡萝卜包」，如果比预期顺，再拍「花卷」；如果累到崩溃，花卷留到下次。**别为了「一次拍两条」把两条都拍糊。**
2. **共用面团**：两条的包子皮/花卷面团配方完全一样（面粉 300g + 酵母 3g + 糖 5g + 温水 160g）。可一次和 **2 团**（各 300g），盖好一起醒。
3. **和面镜头拍一次即可**：两条视频都要和面，同一段画面配不同旁白可复用。想更自然就拍两条不同机位的和面。
4. **醒面的 1 小时不要空等**：用来拍馅、做葱油、拍空镜（素材银行）。

---

## 1. 通用准备清单

### 器材
- [ ] 手机 ×2（或 1 手机 + 1 相机）
- [ ] 俯拍支架（正上方机位）
- [ ] 侧机位支架（拍手部/侧脸）
- [ ] 补光灯（阴天/晚上用，暖白）
- [ ] 小蜜蜂/领夹麦（录口播）；环境原声用手机自带麦即可

### 道具
- [ ] 干净的案板、擀面杖、蒸屉 + 蒸笼纸、保鲜膜
- [ ] 白瓷盘/白碗（试吃、成品）
- [ ] 生活物件：一杯水、一本摊开的书、窗边绿植（把「宿舍」变「家」）

### 食材
**面团（两条共用，各 300g）**
- 面粉 300g ×2 ｜ 酵母 3g ｜ 糖 5g ｜ 温水 160g

**包子馅**
- 韭菜 250g ｜ 鸡蛋 4 个 ｜ 胡萝卜 1 根 ｜ 粉丝 1 把 ｜ 虾皮（可选）
- 香油 2 勺 ｜ 蚝油 1 勺 ｜ 白胡椒 ｜ 盐（最后放）

**花卷**
- 小葱 1 把 ｜ 食用油 ｜ 盐 ｜ 花椒粉/五香粉（可选）
- 油酥（选做）：面粉 2 勺 + 热油 3 勺

### 机位固定规范
- A 机：正俯拍（手部操作主体）
- B 机：侧 45°（拍手、侧面、蒸汽、力度感）
- **每个关键动作，两条都拍 A + B**，后期二选一

## 2. 拍摄时间表（约 4–5 小时，含等待）

| 时间 | 动作 |
|---|---|
| 0:00–0:40 | 摆台、架机位、试光试音、备料 |
| 0:40–0:55 | **和面 ×2**（A/B 机），盖膜 |
| 0:55–1:00 | 拍空镜（阳光、案板、面粉、绿植）——素材银行 |
| 1:00–1:40 | 醒面等待：**做包子馅**（韭菜、炒蛋、炒胡萝卜、粉丝、拌馅）+ 拍 |
| 1:40–2:00 | **做花卷葱油** + 拍 |
| 2:00–2:20 | 醒面完成：拍面团蜂窝特写（两条共用） |
| 2:20–3:00 | **包包子**（擀皮、捏褶、摆屉、二次醒发）+ 拍 |
| 3:00–3:15 | 包子冷水上锅蒸 12 分钟（水开计时） |
| 3:15–3:35 | 蒸包子期间：**擀花卷、卷花卷**（第 2 集关键镜头） |
| 3:35–3:40 | 包子开盖 + 焖 3 分钟 + **试吃**（第 1 集钩子&结尾） |
| 3:40–4:00 | 花卷二次醒发 + 上锅蒸 12–15 分钟 |
| 4:00–4:15 | 花卷开盖、试吃（第 2 集钩子&结尾） |
| 4:15–4:45 | 补拍：空镜、书/窗、手部特写、试吃表情、封面镜头 |

> 拍摄间隙随手多录 3–5 秒「安静画面」，剪辑时当呼吸感用。

---

## 3. 共用素材清单（拍一次，两条都能用）

- [ ] 空镜：阳光、案板、面粉、窗边绿植、窗外（各 5–8s，横竖都拍）
- [ ] 手部特写：手沾面粉、揉面、擀面（各 3–5s）
- [ ] 蒸汽：开盖、锅盖缝隙（各 3–5s）
- [ ] 面团蜂窝特写（两条共用）
- [ ] 生活片段：摊开的书、喝水、窗外、猫（有就拍）
- [ ] 试吃镜头：两条各拍「闭眼/点头」各 2 条
- [ ] 封面镜头：包子、花卷各拍 5–8 张不同角度

> 日常积累的空镜见 `素材银行清单.md`。

## 4. 后期清单（每条都走一遍）

- [ ] 片头 3 秒：成品 + 标题
- [ ] 配方分步出现（不要开头全放），完整版留评论区置顶
- [ ] 大字卡：包子=先油后盐/二次醒发/焖3分钟；花卷=葱花先拌油/卷紧再切/焖3分钟
- [ ] 原声保留：切菜、揉面、泼油、蒸汽，BGM 不压原声
- [ ] 结尾：试吃 + 互动提问
- [ ] 封面：成品 + 热气 + 「毕业生食谱」小字 + 一句钩子
- [ ] 导出 60s 竖版；另存长版素材文件夹
