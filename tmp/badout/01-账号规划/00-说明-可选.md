# 01 · 对外运营方案说明（可选）

> **这一部分是可选的。**
> 账号的核心是 **`05-食谱库/`（私人食谱库 / 工具箱）**。
> `01-账号规划`、`02-分集脚本`、`03-拍摄手册`、`04-运营记录` 都是「**如果要把食谱做成对外短视频**」时才有用。

## 什么时候用这一套
- 想把做饭过程发到小红书 / 抖音 / B站 → 看 `02-分集脚本` + `03-拍摄手册`
- 想规划账号方向、栏目、数据、变现 → 看 `01-账号规划`
- 已经发布、要记录数据 → 看 `04-运营记录`

## 什么时候可以忽略
- 只想**给自己攒食谱** → 直接用 `05-食谱库/`，其余全部不看。

## 边界
即使对外运营，内容也必须遵守 `AGENTS.md` 的护栏：不卖惨、不消费「毕业/失业」梗、踏实记录。
