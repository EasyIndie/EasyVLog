## 2. 构建管线

`index.html` 是一张**模板**（带 `__BASE__` / `__TITLE__` / `__SITE_JSON__` 等占位符），**不能直接双击打开**。
`preview.sh` 里就是这几步，顺序不能乱：

| 步骤 | 脚本 | 产出 |
|---|---|---|
| 1 | `node scripts/build-recipes.mjs` | `01-食谱收集/00-食谱索引.md` |
| 2 | `node scripts/build-index.mjs` | `02-视频脚本/00-脚本索引.md` |
| 3 | `node scripts/build-site.mjs` | `site.json`（导航清单） |
| 4 | `node scripts/build-static.mjs --base / --out _site` | 每篇 md 渲染成真 HTML，组装 `_site/`（含 sitemap、Service Worker） |

- 产物全在 `_site/`（已 `.gitignore`）。首次渲染在构建期完成（SEO 的关键），`assets/app.js` 只做渐进增强。
- `build-static.mjs` **按 `site.json` 自动拷贝**导航里出现的顶层文件 / 目录，加内容目录不用改它。
- 构建期有断言：缺 front matter、导航指向不存在的文件、页面重复样式表等会直接失败。

## 3. 本地预览

```bash
./scripts/preview.sh              # 构建 + 起服务 http://127.0.0.1:8000
./scripts/preview.sh 8080         # 指定端口
./scripts/preview.sh --watch      # 常驻：改源文件自动重建，刷新浏览器即可
./scripts/stop-preview.sh         # 停止预览（watch + 服务）
```

`--watch` 由 `scripts/watch.mjs` 监听 `01`~`04` / `assets` / `data` 与 ROOT 说明文档，防抖 + 串行重建；服务常驻不重启，Ctrl+C 一并退出。

## 4. 脚本与命令

| 命令 | 作用 |
|---|---|
| `node scripts/build-recipes.mjs` | 重建食谱索引 |
| `node scripts/build-index.mjs` | 重建脚本索引 |
| `node scripts/build-site.mjs` | 重建站内导航 `site.json` |
| `node scripts/build-static.mjs --base / --out _site` | 静态化并组装 `_site/` |
| `./scripts/preview.sh [端口] [--watch]` | 本地构建 + 预览 |
| `./scripts/stop-preview.sh` | 停止本地预览 |
| `python3 scripts/make-icons.py` | 重新生成 favicon / PWA 图标 / 分享图 |
| `node scripts/set-today.mjs "名称" [--note "..."]` | 设置站点「今日要做」 |
| `./scripts/look.sh [文件]` | 用 glow 浏览文档 |
| `git push`（main） | 触发 Actions 自动重建并部署 Pages |

内容脚手架（`new-recipe` / `new-episode`）见 `../03-创作指南/创作指南.md`。

## 6. 部署

推 `main` → `.github/workflows/deploy-pages.yml` 自动构建并部署 GitHub Pages。

- 线上：`https://easyindie.github.io/EasyVLog/`
- 部署 `--base /EasyVLog/`；**本地预览用 `--base /`**，别混。
- PWA：`sw.js` 构建期注入版本号，离线可看。

**改完站点复检：**

```bash
./scripts/preview.sh --watch
node --check assets/app.js && node --check sw.js
node scripts/build-static.mjs --base /EasyVLog/ --out _site   # 含导航 / 页面断言
```

人工过一遍：手机「目录」上滑面板、计时器、底部标签栏、桌面侧栏、深浅色切换不闪白、键盘 Tab、打印预览、断网刷新。
