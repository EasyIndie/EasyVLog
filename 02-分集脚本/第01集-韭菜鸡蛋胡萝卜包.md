## 拍摄要点

- **单机位拍法**（只有 1 台手机）：
  - 手机固定在**俯拍支架**上当主力（A），全程不动，先把完整流程的骨架拍下来。
  - 需要侧拍 / 手部特写（B）时，把手机取下**手持**补拍——**只补可重复的动作**（揉面、擀皮、捏褶、切拌、擦丝），拍完放回支架继续。
  - **不可重复的瞬间一次拍成**（倒水、放盐、上锅、开盖、试吃），提前定好角度，不指望 NG 重来。
  - 拍 **4K 竖版**，后期裁到 1080 出「特写」，弥补没有第二机位。
- 运镜：手入画、拿食材挡镜头、蒸汽转场、保鲜膜转场
- 原声：切菜、揉面、打蛋、炒胡萝卜、蒸汽**必须保留**
- 露脸策略：可只露手 + 侧背影；若露脸，起床/端包子/试吃各 1 个镜头即可
- 配色加分点：**韭菜绿 + 胡萝卜橙 + 白面团**，俯拍时颜色很上镜，多拍几张封面
- **「没有粉丝」只当配料梗用**，别在文案里求关注、卖惨

### 拍摄当日时间表（单人，约 2.5 小时）

| 时间 | 动作 |
|---|---|
| 0:00–0:20 | 摆台、架机位、试光试音、称料 |
| 0:20–0:40 | 和面（俯拍 → 手持补一条）→ 盖膜；顺手拍空镜 |
| 0:40–1:45 | 醒面：韭菜洗净晾干 → 调馅（俯拍 + 补特写） |
| 1:45–2:05 | 蜂窝特写、排气、搓条、擀皮 |
| 2:05–2:35 | 包 + 二次醒发 10–15 分钟 + 冷水上锅蒸 12 分钟 + 焖 3 分钟 |
| 2:35–2:55 | 开盖、试吃、**补拍钩子 / 封面**、再补两条空镜 |

### 拍摄中三件事

1. 可重复的动作（揉面、擀皮、捏褶、切拌）**先俯拍再手持补一条**；不可重复的（倒水、上锅、开盖、试吃）**一次拍成**。
2. 切菜 / 揉面 / 打蛋 / 蒸汽的**原声必须干净**，现场别放音乐。
3. 至少留一处真实感：**捏褶捏不好**、面揉得不够光——保留，别重拍成完美。

> 钩子（1-1）和封面要的是**成品**：收尾用刚蒸好的包子补拍，剪辑时挪到片头。
