# 毕业生食谱 · 项目总览

> **账号名**：毕业生食谱
> **定位**：一个男生，在家学做饭。配方给你，翻车也给你看。
> **呈现**：本人不出镜、不配人声；画面 + 字幕叙事，音频只用可选背景音（也可静音）。
> **调性**：踏实、笃定、不慌；只记录，不抒情。
> **主平台**：小红书　｜　分发：抖音（短版）、B站（长版）

---

## 这是什么

一个**私人食谱库 + 日常记录**，对外以短视频形式发布。

- **对内（核心）**：把每次做的东西攒成可复用的食谱卡。
- **对外（可选）**：把过程剪成短视频发出去（小红书为主）。

## 快速开始

**只想攒食谱（核心）**
```bash
node scripts/new-recipe.mjs "韭菜鸡蛋胡萝卜包" --category "包子"
```
填食材、步骤、避坑，保存后索引自动更新。

**想对外发布（可选）**
1. 读 `01-账号规划/01-定位与调性.md`，建立整体认知。
2. 开拍前：打开对应分集脚本 + `01-账号规划/03-拍摄发布SOP.md`。
3. 发布后：填 `04-运营记录/发布与复盘表.md`。

## 在线查看（手机可看）

发布地址：**https://easyindie.github.io/EasyVLog/**

- 手机打开默认进入**「今日要做」**那道菜（置顶高亮）；可搜索、可打印。
- 手机上导航在**底部标签栏**（目录 / 今日 / 食谱 / 脚本），「目录」为底部上滑面板；桌面端为左侧栏常驻。
- **计时器**：食谱「步骤」里的时长（如「12 分钟」）可点，点一下开始倒计时（手机在底部圆钮，桌面在顶栏）。时间到响铃 + 震动。
- **页首信息条**：食谱页标题下是一行 chip（份量 / 耗时 / 难度 / 分类 / 关联视频），值来自 front matter，正文里不要再写一遍。
- 深浅色跟随系统，可手动切换；支持打印、键盘快捷键（`/` 搜索、`Esc` 关闭、`j`/`k` 翻页）。

切换「今日要做」：
```bash
node scripts/set-today.mjs "花卷" --note "第 02 集"
```

### 站点是怎么生成的

`index.html` 是一张**模板**（带 `__BASE__` / `__TITLE__` / `__BODY__` 占位符）。
`node scripts/build-static.mjs` 把每篇 Markdown 渲染成真 HTML，输出到 `_site/`（首屏有正文，SEO 友好），`assets/app.js` 只做渐进增强。

**直接双击仓库里的 `index.html` 没用**（占位符没替换），请用：

```bash
./scripts/preview.sh              # 构建到 _site/ 并起服务，默认 http://127.0.0.1:8000
./scripts/preview.sh 8080         # 指定端口
./scripts/preview.sh --watch      # 常驻：改源文件自动重建，刷新浏览器即可
```

`--watch` 下静态服务不用重启，只重建 `_site/`；`_site/` 在 `.gitignore` 里，不会污染仓库。

## 发布与维护

**发布内容**：`git add -A && git commit -m "内容: ..." && git push`
推送 `main` 后 GitHub Actions 自动重建索引与站点并部署（`.github/workflows/deploy-pages.yml`），无需手动构建。

**改完站点，复检清单：**
```bash
./scripts/preview.sh
node --check assets/app.js && node --check sw.js
node scripts/build-static.mjs --base /EasyVLog/ --out _site   # 含导航断言
```
人工过一遍：手机目录上滑/计时器/底部标签、桌面侧栏、深浅色切换不闪白、键盘 Tab、打印预览、断网刷新。

改动历史见 `CHANGELOG.md`。**本仓库所有文档以「当前」为准，废弃方案只留在 `CHANGELOG.md`。**
