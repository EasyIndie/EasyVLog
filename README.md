# 毕业生食谱

> 一个男生，在家学做饭。配方给你，翻车也给你看。
> 踏实、笃定、不慌；只记录，不抒情。

一个**私人食谱库 + 面食短视频**的内容仓库，附一个可离线看的在线站。

发布地址：**https://easyindie.github.io/EasyVLog/**
