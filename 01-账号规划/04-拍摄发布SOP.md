# 04 · 拍摄发布 SOP

## 拍摄

- 首条**只拍 1 条**，记录真实耗时和难点，再定产能（别低估一个人边做边拍的成本）
- 跑通后：周末一次拍 2–3 条（备 3 种馅、和 3 团面）
- **素材银行**：日常随手拍空镜（阳光、雨、街道、书、绿植），随取随用 → 见 `03-拍摄手册/素材银行清单.md`
- 每条必备：开头钩子、分步配方、关键大字卡、结尾互动

## 剪辑

- 固定片头：3 秒成品 + 标题
- 固定字幕样式：配方分步出现，关键句大字卡
- 固定 BGM：轻治愈系，音量不压原声；只用平台曲库（版权）
- 固定结尾：试吃 + 互动提问

## 发布

- 节奏：**每周 3 更**，周二、周四、周日；始终留 1 条库存缓冲
- 时间：工作日 11:30–12:30、17:30–19:00；周末早上
- 一鱼多吃：60s 正片 + 完整版 + 图文配方 + 30s 高光
- 标签见 `03-栏目与选题库.md`

## 一鱼多吃流程

1. 拍 1 次完整素材
2. 剪 60s 竖版（抖音/视频号）
3. 剪 90s 完整版 + 图文配方（小红书）
4. 剪 2–3min 长版（B站）
