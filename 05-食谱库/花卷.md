# 花卷

## 开工前

- 等待时间：面团发酵约 1 小时，二次醒发 15 分钟；中间在等，不用守着。
- 要提前做的：小葱洗净晾干切碎；醒面的时间正好做葱油。
- 工具：蒸屉 + 蒸笼纸、擀面杖、筷子、保鲜膜

## 食材

### 面团

| 材料 | 用量 | 备注 |
|---|---|---|
| 中筋面粉 | 300 g | |
| 酵母 | 3 g | |
| 糖 | 5 g | 帮助发酵 |
| 温水 | 160 g | 约 35°C |

### 葱油

| 材料 | 用量 | 备注 |
|---|---|---|
| 小葱 | 1 把 | |
| 食用油 | 适量 | 烧热泼香 |
| 盐 | 适量 | |
| 花椒粉 / 五香粉 | 少许 | 可选 |

### 油酥（选做，层次更分明）

| 材料 | 用量 | 备注 |
|---|---|---|
| 面粉 | 2 勺 | |
| 热油 | 3 勺 | 浇在面粉上 |

## 步骤

1. 温水化开酵母，加面粉、糖，揉成光滑面团，盖膜醒至两倍大。
2. 小葱切碎，加盐、花椒粉，**淋热油泼香**（可另做油酥）。
3. 面团排气，擀成大薄片（越薄层次越多）。
4. 抹油（或油酥），撒盐和葱花。
5. 从一侧卷起成条，**卷紧**，切成段；两段叠起，用筷子从中间一压成花。
6. 摆进蒸屉，留空隙，**二次醒发 15 分钟**。
7. 水开蒸 12 分钟，**关火焖 3 分钟**再开盖。

## 避坑

- **葱花发黄发苦**：葱花先裹上油（泼热油或拌油）再包。
- **层次少、吃着像馒头**：面擀薄一点，卷紧一点。
- **蒸完散开**：卷松了，卷的时候要卷紧。
- **回缩、塌陷**：关火焖 3 分钟再开盖。
- 卷得丑不影响味道，第一次别追求好看。

## 变体

- 加麻酱 + 椒盐 → 麻酱花卷。
- 加红糖 + 芝麻 → 糖花卷。
- 加南瓜泥和面 → 南瓜花卷（颜色好看）。
