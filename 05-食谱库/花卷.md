# 花卷

## 基本信息

- 分类：馒头花卷
- 份量：约 8 个
- 耗时：约 2 小时（含发酵）
- 难度：简单
- 关联视频：第 02 集
- 工具：蒸屉 + 蒸笼纸、擀面杖、筷子、保鲜膜

## 食材

### 面团

| 材料 | 用量 | 备注 |
|---|---|---|
| 中筋面粉 | 300 g | |
| 酵母 | 3 g | |
| 糖 | 5 g | |
| 温水 | 160 g | 约 35°C |

### 葱油

| 材料 | 用量 | 备注 |
|---|---|---|
| 小葱 | 1 把 | 切碎 |
| 食用油 | 适量 | 烧热泼香 |
| 盐 | 适量 | |
| 花椒粉 / 五香粉 | 少许 | 可选 |

### 油酥（选做，层次更分明）

| 材料 | 用量 |
|---|---|
| 面粉 | 2 勺 |
| 热油 | 3 勺 |

## 步骤

1. 温水化开酵母，加面粉、糖，揉成光滑面团，盖膜醒至两倍大。
2. 小葱切碎，加盐、花椒粉，**淋热油泼香**（可另做油酥）。
3. 面团排气，擀成大薄片（越薄层次越多）。
4. 抹油（或油酥），撒盐和葱花。
5. 从一侧卷起成条，切成段；两段叠起，用筷子从中间一压成花。
6. 摆进蒸屉，留空隙，二次醒发 15 分钟。
7. 水开蒸 12 分钟，**关火焖 3 分钟**再开盖。

## 关键点 / 避坑

- **葱花先拌油**：不然蒸出来发黄发苦。
- **面擀薄一点**：层次才多。
- **卷紧一点**：卷松了蒸完会散。
- **焖 3 分钟**：防止回缩。
- 卷得丑没关系，味道一样（真实感也是内容）。

## 变体

- 加麻酱 + 椒盐 → 麻酱花卷。
- 加红糖 + 芝麻 → 糖花卷。
- 加南瓜泥和面 → 南瓜花卷（颜色好看）。
