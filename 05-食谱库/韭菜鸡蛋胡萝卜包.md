# 韭菜鸡蛋胡萝卜包

## 基本信息

- 分类：包子
- 份量：约 12 个
- 耗时：约 2.5–3 小时（含发酵）
- 难度：简单
- 关联视频：第 01 集
- 工具：蒸屉 + 蒸笼纸、擀面杖、保鲜膜、擦丝器

## 食材

### 面团

| 材料 | 用量 | 备注 |
|---|---|---|
| 中筋面粉 | 300 g | |
| 酵母 | 3 g | |
| 糖 | 5 g | 帮助发酵 |
| 温水 | 160 g | 约 35°C，别烫手 |

### 馅

| 材料 | 用量 | 备注 |
|---|---|---|
| 韭菜 | 250 g | 洗净**晾干**再切 |
| 鸡蛋 | 4 个 | 炒碎放凉 |
| 胡萝卜 | 1 根（约 150 g） | 擦丝，少油略炒软 |
| 粉丝 | 1 把 | **可选**，泡软切碎（吸水、增口感） |
| 虾皮 | 可选 | 提鲜 |
| 香油 | 2 勺 | 先拌韭菜 |
| 蚝油 | 1 勺 | |
| 白胡椒 | 少许 | |
| 盐 | 最后放 | 防出水 |

## 步骤

1. 温水化开酵母，加面粉、糖，揉成光滑面团，盖膜醒至两倍大（内部蜂窝状）。
2. 韭菜洗净晾干切碎，**先淋香油拌匀**（先油后盐，锁水不出水）。
3. 鸡蛋打散，热锅凉油炒碎，盛出放凉。
4. 胡萝卜擦丝，锅少油**略炒软**，盛出放凉（去生味、更甜更软）。
5. 粉丝泡软切碎。
6. 韭菜、鸡蛋、胡萝卜、粉丝混合，加蚝油、白胡椒，**盐最后放**，拌匀。
7. 面团排气，搓条切剂，擀成**中间厚边缘薄**的皮。
8. 多放馅，捏褶收口（不会捏就收圆，味道一样）。
9. 摆进蒸屉，留空隙，**二次醒发 10–15 分钟**。
10. 冷水上锅，水开蒸 12 分钟，**关火焖 3 分钟**再开盖。

## 关键点 / 避坑

- **胡萝卜先炒软**：去生味，口感更甜更软。
- **炒过的胡萝卜要放凉再拌**：不然会把韭菜烫熟、烫出味。
- **先油后盐**：韭菜先拌油，锁住水分。
- **盐最后放**：防止馅料出水。
- **没有粉丝也能做**：粉丝只是吸水增口感。没有就——① 多炒 1 个鸡蛋；② 加 1–2 勺面粉/淀粉吸水分；③ 胡萝卜炒软也能吸一点水。
- **韭菜要晾干**：带水下锅，馅会稀。
- **二次醒发不能省**：省了蒸出来不暄。
- **焖 3 分钟**：关火别马上开盖，防止回缩塌陷。

## 变体

- **没有粉丝**：直接省掉。靠「韭菜晾干 + 先油后盐 + 盐最后放」控水，最多加 1 个鸡蛋或 1–2 勺面粉。
- **不加胡萝卜** = 经典韭菜鸡蛋包。
- 加虾皮提鲜。
- 胡萝卜换成木耳 / 香菇碎。
- 想更香：鸡蛋炒的时候油多一点，炒得碎而蓬松。
