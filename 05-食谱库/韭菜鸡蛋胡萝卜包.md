# 韭菜鸡蛋胡萝卜包

## 开工前

- 等待时间：面团发酵约 1 小时，二次醒发 10–15 分钟；大部分时间在等，不用守着。
- 要提前做的：韭菜洗净**晾干**；粉丝要吃的话提前泡软。
- 工具：蒸屉 + 蒸笼纸、擀面杖、保鲜膜、擦丝器

## 食材

### 面团

| 材料 | 用量 | 备注 |
|---|---|---|
| 中筋面粉 | 300 g | |
| 酵母 | 3 g | |
| 糖 | 5 g | 帮助发酵 |
| 温水 | 160 g | 约 35°C，别烫手 |

### 馅

| 材料 | 用量 | 备注 |
|---|---|---|
| 韭菜 | 250 g | |
| 鸡蛋 | 4 个 | |
| 胡萝卜 | 1 根（约 150 g） | |
| 粉丝 | 1 把 | 可选，吸水增口感 |
| 虾皮 | 可选 | 提鲜 |
| 香油 | 2 勺 | |
| 蚝油 | 1 勺 | |
| 白胡椒 | 少许 | |
| 盐 | 适量 | **最后放** |

## 步骤

1. 温水化开酵母，加面粉、糖，揉成光滑面团，盖膜醒至两倍大（内部蜂窝状）。
2. 韭菜洗净**晾干**，切碎，先淋香油拌匀。
3. 鸡蛋打散，热锅凉油炒碎，盛出**放凉**。
4. 胡萝卜擦丝，锅少油**炒软**，盛出**放凉**。
5. 韭菜、鸡蛋、胡萝卜（和泡软切碎的粉丝）混合，加蚝油、白胡椒，**盐最后放**，拌匀。
6. 面团排气，搓条切剂，擀成**中间厚边缘薄**的皮。
7. 多放馅，捏褶收口（不会捏就收圆，味道一样）。
8. 摆进蒸屉，留空隙，**二次醒发 10–15 分钟**。
9. 冷水上锅，水开蒸 12 分钟，**关火焖 3 分钟**再开盖。

## 避坑

- **馅出水、包不住**：韭菜一定晾干；记住「先油后盐 + 盐最后放」，别提前调味。
- **吃到生胡萝卜味、发硬**：胡萝卜要少油炒软，别直接拌生的。
- **韭菜被烫出味**：炒好的鸡蛋、胡萝卜都放凉再拌。
- **皮破 / 漏汤**：皮擀中间厚边缘薄，馅别塞到边缘。
- **蒸完发硬、不暄**：二次醒发别省（手按能回弹）；关火焖 3 分钟再开盖，防止回缩。

## 变体

- **没有粉丝**：直接省掉，靠「晾干韭菜 + 先油后盐 + 盐最后放」控水；也可加 1 个鸡蛋或 1–2 勺面粉吸水。
- **有粉丝版**：加 1 把粉丝泡软切碎，吸水又增口感。
- 不加胡萝卜 = 经典韭菜鸡蛋包。
- 加虾皮提鲜；胡萝卜换成木耳 / 香菇碎。
- 想更香：炒鸡蛋时油多一点，炒得碎而蓬松。
