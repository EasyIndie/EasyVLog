# 食谱卡写作

## 定位
`03-食谱库/` 是账号的**核心**——私人食谱收集 + 工具箱。目标：**任何一张卡都能被独立复刻**，不依赖视频。

## 写作前必读
1. `AGENTS.md`（护栏，最高优先级）
2. `创作指南.md`（创作侧总说明）
3. `03-食谱库/_模板.md`（结构）
4. `03-食谱库/韭菜鸡蛋胡萝卜包.md`（范例）

## 卡片结构

正文五节，做的时候从上往下看就行：

1. **开工前**：等待时间、要提前做的（泡发 / 晾干 / 放凉）、工具。front matter 装不下的才写这里。
2. **食材**：按组分表，**备注只写「这是什么 / 能不能换」**，不写怎么做。
3. **步骤**：一步一个动作，火候 / 时间 / 状态写具体；关键顺序在步骤里加粗。
4. **避坑**：只写失败原因和怎么避免；**步骤里已经说清的不再抄一遍**。
5. **变体**：换料 / 加减。

**一个事实只写一处**：同一句「胡萝卜炒软」不要在食材备注、步骤、避坑里各写一遍。
视频专属的说法（本集怎么拍、彩蛋、「这集没放粉丝」）**不进食谱卡**，放分集脚本；食谱卡要能独立复刻。

## 硬性规则
1. **食材必须带克数/个数量**，能照着做。
2. **关键顺序要写明**（例如「盐最后放」「先油后盐」）。
3. **必须有「避坑」**：把容易失败的地方列出来，只写原因和对策。
4. 步骤用编号，每步一个动作。
5. **不消费「毕业/失业」梗**；语气朴实。
6. 中文、UTF-8。

## 步骤写法
- 只说操作，不抒情。
- 火候/时间/状态要具体：「水开蒸 12 分钟」「揉到光滑」「醒至两倍大」。
- 关键顺序（盐最后放、先油后盐、放凉再拌）在步骤里加粗，不要只写在底部。
