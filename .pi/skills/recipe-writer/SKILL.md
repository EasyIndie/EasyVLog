# 食谱卡写作

## 定位
`05-食谱库/` 是账号的**核心**——私人食谱收集 + 工具箱。目标：**任何一张卡都能被独立复刻**，不依赖视频。

## 写作前必读
1. `05-食谱库/_模板.md`（结构）
2. `05-食谱库/韭菜鸡蛋胡萝卜包.md`（范例）
3. `AGENTS.md`（护栏）

## front matter
```yaml
---
id: 3
name: 名称
category: 包子        # 包子/馒头花卷/饺子馄饨/面条/饼/馅料/基础面团/汤菜
tags: [发面, 蒸]
difficulty: 简单
time: 150 分钟
servings: 约 12 个
source: 第 03 集      # 无视频可留空
created: 2026-09-27
updated: 2026-09-27
---
```

## 硬性规则
1. **食材必须带克数/个数量**，能照着做。
2. **关键顺序要写明**（例如「盐最后放」「先油后盐」）。
3. **必须有「关键点 / 避坑」**：把容易失败的地方列出来。
4. 步骤用编号，每步一个动作。
5. **不消费「毕业/失业」梗**；语气朴实。
6. 中文、UTF-8。

## 步骤写法
- 只说操作，不抒情。
- 火候/时间/状态要具体：「水开蒸 12 分钟」「揉到光滑」「醒至两倍大」。

## 完成后
```bash
node scripts/build-recipes.mjs
```
