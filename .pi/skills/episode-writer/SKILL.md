# 分集脚本写作

## 写作前必读
1. `AGENTS.md`（护栏，最高优先级）
2. `01-账号规划/01-定位与调性.md`
3. `02-分集脚本/第01集-韭菜鸡蛋胡萝卜包.md`（格式与调性范例）

## 硬性规则（违反即重写）

1. **禁用词**（正文/字幕/标题/简介中一个都不能出现；**账号名「毕业生食谱」是唯一例外**）：失业、被裁、毕业、下岗、找不到工作、gap、躺平、啃老。
2. 不卖惨、不焦虑、不自嘲；不渲染孤独；不写「一个人也要好好生活啊」式抒情。
3. 第一人称经验分享：「我试下来」「我也翻车过」；禁止「你应该」「很多人做错了」。
4. 字幕去掉「呀/啦/哦/呢」。
5. 配方分步出现，**不要在 0–8 秒全给**；完整版放评论区置顶。
6. 主版固定 **60 秒**。
7. 昵称统一「毕业生食谱」。
8. **不消费「毕业/失业」梗**：名字是软双关，内容**绝不能**往「失业生存指南」「被裁后怎么省钱」方向偏。
9. **不出镜、无人声**：本人不出镜（只拍手 / 操作 / 成品），视频不配人声。脚本里**不写口播 / 旁白 / 配音**；逐镜表给的是**字幕**，音频只有可选背景音。

## 文件结构（一集只留这些）

正文分三节，现场只需读第一节：

1. **一、拍摄执行卡**（现场照着做）：开拍前清单 → 配方（分步）→ 逐镜表（`# | 时间 | 做什么 | 字幕`）→ 收尾三件事 → 大字卡 / 封面钩子。
2. **二、本集准备**（拍摄前一天）：采购（含余量）、本集特有道具、顺手拍的空镜、单人时间线。
3. **三、备注**（剪辑 / 发布）：标题、长版补充、置顶配方引用、标签。

**不要写进分集脚本**（通用内容，统一放 `01-账号规划/03-拍摄发布SOP.md`）：器材清单、机位规范、批量拍摄时间表、素材银行、剪辑规范。脚本里再抄一份，现场就没人愿意照着拍了。

## 60 秒结构模板

```
0–3s    钩子：成品特写 / 开盖热气 / 掰开横截面 + 一句定位
3–8s    空镜过渡 + 「配方放屏幕」
8–22s   核心步骤 1（和面）
22–35s  核心步骤 2（调馅 / 做葱油）
35–47s  核心步骤 3（包 / 卷）
47–56s  蒸制 + 开盖（情绪高点）
56–60s  成品掰开 + 互动提问
```

大字卡**只留 3 个**，是这条视频最该被记住的 3 个要点。

## 字幕写法
- 字幕是唯一的叙述载体：画面 + 字幕要能独立看懂，不依赖声音。
- 每句一个信息点，短句；一行别太长，手机上要一眼看完。
- 讲事实、步骤、失败原因，不讲情绪。
- 例：「先油后盐，我上次没这样做，馅全是水。」

## 配方写法
- 必须含**克数/个数量**，能独立复刻。
- 给关键比例和顺序，例如「盐最后放」。
- 完整配方放 `05-食谱库/` 食谱卡；脚本只引用，不另抄一份。

## 真实感设计（每条至少一处）
- 手笨、捏得不好看、卷得不齐
- 一次小失败 + 原因 + 改进（不要长期只翻车）
