# 分集脚本写作

## 写作前必读
1. `AGENTS.md`（护栏，最高优先级）
2. `01-账号规划/01-定位与调性.md`
3. `02-分集脚本/第01集-韭菜鸡蛋包.md`（格式与调性范例）

## 硬性规则（违反即重写）

1. **禁用词**：失业、被裁、毕业、下岗、找不到工作、gap、躺平、啃老。
2. 不卖惨、不焦虑、不自嘲；不渲染孤独；不写「一个人也要好好生活啊」式抒情。
3. 第一人称经验分享：「我试下来」「我也翻车过」；禁止「你应该」「很多人做错了」。
4. 旁白去掉「呀/啦/哦/呢」。
5. 配方分步出现，**不要在 0–8 秒全给**；完整版放评论区置顶。
6. 主版固定 **60 秒**。
7. 昵称统一「醒面日记」。

## 60 秒结构模板

```
0–3s    钩子：成品特写 / 开盖热气 / 掰开横截面 + 一句定位
3–8s    空镜过渡 + 「配方放屏幕」
8–22s   核心步骤 1（和面）
22–35s  核心步骤 2（调馅 / 做葱油）
35–47s  核心步骤 3（包 / 卷）
47–56s  蒸制 + 开盖（情绪高点）
56–60s  试吃 + 互动提问
```

大字卡**只留 3 个**，是这条视频最该被记住的 3 个要点。

## 口播写法
- 每句一个信息点，短句。
- 讲事实、步骤、失败原因，不讲情绪。
- 例：「先油后盐，我上次没这样做，馅全是水。」

## 配方写法
- 必须含**克数/个数量**，能独立复刻。
- 给关键比例和顺序，例如「盐最后放」。
- 结尾附「评论区置顶」用的完整配方。

## 真实感设计（每条至少一处）
- 手笨、捏得不好看、卷得不齐
- 一次小失败 + 原因 + 改进（不要长期只翻车）

## front matter
按 `AGENTS.md` 第 5 节填写；`status` 初始为 `脚本`。

## 完成后
```bash
node scripts/build-index.mjs
```
