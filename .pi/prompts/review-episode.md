逐项检查并给出结论：

1. **护栏**：是否出现禁用词（失业/被裁/毕业/下岗/gap/躺平/啃老；**账号名「毕业生食谱」是唯一例外**）、卖惨、爹味说教、软虚词（呀/啦/哦/呢）、开头就把配方全给出；以及是否消费「毕业/失业」梗。
2. **调性**：是否踏实笃定、第一人称经验分享、只记录不抒情。
3. **呈现方式**：是否**不出镜、无人声**；不应出现口播 / 旁白 / 配音，叙事完全靠画面 + 字幕。
4. **结构**：是否 60 秒、有 3 秒钩子、大字卡 3 个、结尾有互动提问；**拍摄执行卡能否直接照着做**（逐镜表只有「做什么 / 字幕」两列核心信息，字幕是短句，通用器材/机位没重复写进来）。
5. **配方**：能否独立复刻（克数 / 个数量是否齐全）。
6. **front matter**：字段是否完整、`status` 是否与实际相符。

输出两栏：**必须改** 与 **建议改**，每条给出原文和修改后文本。
