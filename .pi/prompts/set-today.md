---
description: 设置站点首页「今日要做」
argument-hint: "<食谱名或集号> [备注]"
---
把站点首页的「今日要做」设为 **$1**，备注：${2:-（无备注）}。

运行（带备注就加 `--note`）：

```bash
node scripts/set-today.mjs "$1" --note "$2"
```

- 脚本会在 `01-食谱收集/`、`02-视频脚本/`、`03-创作指南/` 里按名称或集号找到对应文档，更新 `data/today.json` 并重建 `site.json`。
- 找不到就如实告诉用户，列出可选的名称。
- 完成后确认首页指向已更新。
