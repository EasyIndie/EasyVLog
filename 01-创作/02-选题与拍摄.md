## 一、选题与栏目

| 栏目 | 内容 | 示例标题 |

| 今天做______ | 包子、馒头、饺子、面条 | 毕业生食谱｜猪肉大葱包，汁水多一点 |

| 今天没出门 | 纯记录，阳光做饭吃饭 | 毕业生食谱｜下雨天，在家包饺子 |

### 标题公式

**毕业生食谱｜食物 + 情绪 / 场景 / 卖点 / 翻车**
例：`毕业生食谱｜周末蒸一锅花卷，满屋面香`

### 标签

`#毕业生食谱 #日常vlog #面食 #新手做饭 #一个人做饭`

## 二、拍摄

- **首条只拍 1 条**，记录真实耗时和难点，再定产能（别低估边做边拍的成本）。
- 跑通后：周末一次拍 2–3 条（备对应份数的面团和馅）。
- 每条必备：开头钩子、分步配方、关键大字卡、结尾互动。
- **呈现**：本人不出镜、不配人声；画面 + 字幕叙事，音频只用可选背景音（见 `01-定位与调性.md`）。

**器材**
- [ ] 手机 ×1（单机位：俯拍为主，可重复动作再手持补；有第二台更省事）
- [ ] 俯拍支架（正上方，核心）；补光灯（阴天 / 晚上，暖白）
- [ ] 不需要麦克风：不配人声，现场声用手机自带麦收即可（可选）

**道具**
- [ ] 案板、擀面杖、蒸屉 + 蒸笼纸、保鲜膜
- [ ] 白瓷盘 / 白碗（成品、掰开展示）
- [ ] 生活物件：一杯水、一本摊开的书、窗边绿植（把「宿舍」变「家」）

**机位**
- A 机：正俯拍（手部操作）；B 机：侧 45°（手、蒸汽、力度感）
- 单机位：A 固定拍完整骨架，可重复的动作再手持补 B；倒水 / 上锅 / 开盖等**不可重复的瞬间一次拍成**；4K 竖拍，后期裁特写

**批量拍摄（以两条发面为例）**
两条共用面团（如 面粉 300g + 酵母 3g + 糖 5g + 温水 160g），可一次和 2 团，和面镜头复用、配不同字幕。醒面的 1 小时用来做馅、做葱油、拍空镜。

| 时间 | 动作 |
|---|---|
| 0:00–0:40 | 摆台、架机位、试光试音、备料 |
| 0:40–1:00 | 和面 ×2（A/B 机），盖膜；顺手拍空镜 |
| 1:00–1:40 | 醒面：做第一道菜的馅料 + 拍 |
| 1:40–2:00 | 做第二道菜的配料（如葱油）+ 拍 |
| 2:00–2:20 | 面团蜂窝特写（两条共用） |
| 2:20–3:40 | 包 / 卷 + 二次醒发 + 上锅 + 开盖 |
| 3:40–4:45 | 补拍：空镜、书 / 窗、手部特写、成品掰开、封面 |

> 一次只跑通一条再上第二条，别为了「一次拍两条」把两条都拍糊。

## 三、素材银行

平时随手拍，剪辑缺「呼吸感」镜头时随时调。

- **厨房 / 案板**：阳光落案板 · 面粉撒台面 · 手沾面粉 · 水龙头流水 · 灶火点燃 · 锅盖水汽
- **生活 / 家**：窗外的树 / 天空 / 雨 · 摊开的书 · 一杯水 / 茶 · 绿植 · 猫（有就拍）
- **声音（可选，当背景音用）**：切菜 · 揉面 · 油锅「滋啦」 · 蒸汽 / 水沸 · 敲鸡蛋 · 窗外雨声

用法：每条开头 / 结尾各留 1 个空镜做呼吸感；转场用「蒸汽」「保鲜膜」「拿食材挡镜头」。
存放：相册建 `素材银行/`，按「厨房 / 生活 / 声音」分类，文件名带年月（不进版本库）。

## 四、剪辑

- **无人声**：字幕是唯一的叙述载体，画面 + 字幕要能独立看懂。
- 固定片头：3 秒成品 + 标题。
- 固定字幕样式：配方分步出现，关键句大字卡（每条只留 3 个）。
- 背景音（可选）：轻缓、克制；BGM 只用平台曲库，也可用现场环境声或静音。
- 固定结尾：成品掰开 + 互动提问（提问落在字幕上，观众到评论区答）。
- 封面：成品 + 热气 + 「毕业生食谱」小字 + 一句钩子。

## 五、发布

- 节奏：**每周 3 更**（周二、周四、周日），始终留 1 条库存缓冲。
- 时间：工作日 11:30–12:30、17:30–19:00；周末早上。
- 一鱼多吃：60s 正片 + 完整版 + 图文配方 + 30s 高光。
- 发布后填 `03-发布与复盘表.md`。
